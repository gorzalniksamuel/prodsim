# Security policy

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues, discussions or pull
requests.

Report them privately through GitHub Security Advisories:
https://github.com/gorzalniksamuel/prodsim/security/advisories/new

Include a description of the problem, the affected version or commit, steps to
reproduce, and the impact you expect. You will get an acknowledgement as soon as the
maintainer can respond; ProdSim is maintained by an individual, so please allow
reasonable time. We ask that you give us a chance to fix the issue before disclosing it
publicly.

## Supported versions

| Version        | Supported                    |
| -------------- | ---------------------------- |
| `main` branch  | Yes                          |
| Pre-release (< 0.1) | No, no security fixes   |
| Latest release | Yes, once releases exist     |

This table will be updated as releases are published.
